# סוכן למיון צילומי מסך

סוכן שמציע לכל צילום מסך נושא ומחכה לאישור או לתיקון שלי, בלי להעביר קבצים.

## איך מריצים
אין צורך להריץ כדי לבדוק את הפרויקט: התוצאות מופיעות בטבלת הניסויים ובצילומי ה-trace.
להרצה עצמית: יוצרים קובץ `.env` עם המפתחות של OpenAI ו-LangSmith, משנים בראש `agent.py` את נתיב התיקייה לסריקה, ולוחצים לחיצה כפולה על `run.bat`.

## ניסויים
| ניסוי | מה שונה | ציון |
|---|---|---|
| 1 | פרומפט פשוט, בלי הענף | 0.81 |
| 2 | הגדרה לכל נושא, עם הענף | 0.81 |

## צילומי trace
כל הצילומים נמצאים בתיקייה `screenshots`.

## תובנה מה-trace
הציון זהה בשני הניסויים, אבל התוצאות שונות: ניסוי 2 תיקן 3 תמונות ושבר 2.
ב-trace של אחת מתמונות הקוד המודל ענה בביטחון `other`. לכן הענף לא הופעל, כי הוא רץ רק כשהמודל עונה `unsure`.
